# AI 面试手册

面向大模型、AI Agent、搜索、广告与推荐方向的中文面试学习资料，按知识体系组织题目，结合参考答案、原理解析、回答角度和追问，帮助准备面试、梳理知识与复盘项目。

目前包含 **4 份专题手册、92 个主题章节、1,120 道编号题**。题量按各文档独立统计，专题之间存在交叉，适合按岗位选择阅读。

## 如何使用

1. **先建立知识地图。** 阅读所选手册的导航、岗位路径和章节目录，识别需要补齐的前置知识。
2. **先答后看。** 选一道题独立回答，再对照参考答案检查概念、机制、适用条件与遗漏点。
3. **练习分层表达。** 先说结论，再展开机制和具体例子，说明方案取舍，最后给出验证方法。
4. **用追问检验理解。** 将追问和易错点作为自测清单，对涉及公式、代码和系统设计的内容动手推导或实现。
5. **结合真实项目复盘。** 用自己的问题背景、个人贡献、实验结果和失败案例组织回答。

文档中的 `P0 / P1 / P2`、基础 / 进阶等标记用于提示学习优先级或理解深度；不同手册的具体约定以各自阅读说明为准。

## 内容范围与资料时效

- 本项目按公开知识体系整理面试学习题目，不宣称收录任何公司的完整私有题库，也不以题目数量代表真实面试频率。
- 现有手册标注的资料核查截止日期为 **2026 年 11 月 5 日**。涉及模型、框架、协议和论文的具体结论，请结合各手册的引用及对应版本阅读。
- 参考答案用于理解原理和组织回答；涉及工程方案与效果时，应结合业务约束、实验条件和实际证据判断。
- 各手册末尾提供参考资料或来源索引，便于继续阅读论文、协议与官方文档。
